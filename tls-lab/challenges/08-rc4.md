# Challenge: RC4 Cipher Enabled

**Port:** 44308  
**Difficulty:** Medium  
**CVE:** CVE-2013-2566  
**OWASP:** A02:2021 – Cryptographic Failures

The server allows the RC4 cipher, which has known biases and is deprecated.

**Hints:**
1. Force the client to negotiate RC4.
2. Use Wireshark or a script to capture and analyze the ciphertext.

**Solution:**
```bash
openssl s_client -connect localhost:44308 -cipher RC4
```
Flag: `BHEDA{tls_rc4_cipher}`
