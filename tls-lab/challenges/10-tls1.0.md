# Challenge: TLS 1.0 Enabled

**Port:** 44310  
**Difficulty:** Easy  
**CVE:** CVE-2011-3389  
**OWASP:** A02:2021 – Cryptographic Failures

The server only supports TLS 1.0, which is deprecated and vulnerable to BEAST.

**Hints:**
1. Force the client to use TLS 1.0.
2. TLS 1.0 allows CBC-mode attacks.

**Solution:**
```bash
openssl s_client -connect localhost:44310 -tls1
```
Flag: `BHEDA{tls_v1_deprecated}`
