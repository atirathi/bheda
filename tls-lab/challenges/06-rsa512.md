# Challenge: Weak RSA 512-bit Key

**Port:** 44306  
**Difficulty:** Medium  
**CVE:** CVE-2017-15361  
**OWASP:** A02:2021 – Cryptographic Failures

The server uses a 512-bit RSA key, which can be factored with modern hardware.

**Hints:**
1. Export the server's public key.
2. Factor the 512-bit RSA modulus using tools like `msieve` or `yafu`.
3. Use the factored primes to reconstruct the private key.

**Solution:**
```bash
openssl s_client -connect localhost:44306 2>/dev/null </dev/null | openssl x509 -pubkey -noout > pubkey.pem
python3 -c "
from Crypto.PublicKey import RSA
from Crypto.Util.number import inverse
key = RSA.importKey(open('pubkey.pem').read())
print('n =', key.n)
# Factor n using msieve or yafu
# p = <factor1>, q = <factor2>
p = 0  # replace with factored p
q = 0  # replace with factored q
d = inverse(key.e, (p-1)*(q-1))
priv = RSA.construct((key.n, key.e, d, p, q))
open('server.key','wb').write(priv.exportKey())
"
```
